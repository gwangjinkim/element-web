LANGUAGES & LEARNING

Understand each other.
Learn along the way.

Translate conversations and read recorded messages when you cannot listen.

New here? Create your own account with the step-by-step setup guide first →

1. Invite the assistant

Add @translate:chat.everyhub.org to your conversation. Agree with the other participants first: the assistant can read this room, and its replies are visible to everyone here. Processing runs on our server.

In Element X, open the conversation, tap its name at the top, then choose Invite people (sometimes under People or Members). Enter the full account above and confirm. Adding someone to a direct message may create a new group conversation: continue there with your friend and the assistant. Wait for the assistant to join, then send !help.

2. Choose a shared language

Send !target english (or !target en), then !auto on. The assistant detects everyone’s messages and translates them into English. Messages already in English receive no reply. Choose another shared target whenever you need it.

Use short codes or English names, for example: en English · de German · ko Korean · uk Ukrainian · ru Russian · pl Polish · el Greek. The model supports 150 languages and variants. Use !lang auto for automatic detection, or !lang russian to set your own writing language. Short and mixed-language messages can be misdetected.

Translate just one message

Send !lang auto persian Hello, how are you? to detect the source and translate only that text into Persian. Or use !lang english persian Hello or !lang en fa Hello. Reply to text with !lang auto persian to translate it once.

!target persian Hello uses your saved source language (automatic by default). Adding text after !learn on/off, !auto on/off, !bot on/off, or !temperature 0.2 also applies that option only to the attached text. No saved settings change. These use the room target; local off suppresses only that request, and room !bot off still silences all requests. !prompt add/set saves instructions; its text is not a message to translate. Use !help detailed for the full rules.

3. Turn on learning mode

Send !learn on to include both the original and the translation in replies for this conversation. Send !learn off for translation-only replies. Original messages remain in the conversation in either mode.

Original (en)

Good morning, my friend.

Translation (en → ru)

Доброе утро, мой друг.

4. Read voice and video messages

Send !transcribe on to automatically transcribe recordings you upload. Your friend can enable it for their recordings too. Or reply to a voice/video message with !transcribe for a one-time transcript.

Audio language is detected automatically. Transcripts are also translated into the shared target when automatic translation is on and the languages differ. Recordings must be under 20 MiB and 10 minutes. Live calls are not recorded or transcribed.

Your controls

Send !bot, !auto, or !learn without an argument to toggle it. The assistant confirms whether it is now on or off. Add on or off to set it explicitly.

!bot off / !bot on
Silence or resume the assistant for everyone in this conversation. Translations and transcripts stop, including one-time requests. Language choices are saved. Any participant can use this switch. Resume applies to new messages; messages sent while off are not translated later. Help and settings remain available while off, as do !model, !prompt and !temperature.
!model
See the installed model and this conversation’s settings.
!temperature 0.2
Set variation for this conversation (0–1; default 0). Higher is more varied, not necessarily more accurate. Send !temperature to view it or !temperature reset to restore 0.
!prompt
Show the exact translation prompt template. !prompt add Use informal language. adds instructions; !prompt set … replaces your conversation’s custom instructions; !prompt reset restores the default. The base translation rules stay in place. These settings apply to everyone here and do not affect other conversations.
!settings
See the shared room settings and your own choices.
!auto off / !auto on
Stop or enable automatic translations for everyone in this conversation.
!transcribe off
Stop automatic transcripts of your own recordings.
!forget
Remove your own source language and recording choices. Shared room settings remain.
!translate en ru Hello
Translate once. You can also reply to text with !translate ru en.
!help
Show a compact command reminder. Use !help details for the full rules.

Target language, automatic translation and learning mode are shared by the conversation. Your source language and recording choices belong to you. The same commands work in the web app, Android, and iPhone. Translations and transcripts can make mistakes; check important details. Automatic text translation supports up to 3,000 characters per message. Longer transcripts remain readable. Translation runs locally using Index-Translate 2B; speech uses Whisper small.
